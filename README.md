# SFX test env

Test copy of the ScoreFex website (v10.3), published with GitHub Pages at https://scorefex.github.io/sfx-test-env/ so it can be opened on any device.

This folder holds the built site only. The source lives in `scorefex_website_v10_3`; it is built with `vite build --base=/sfx-test-env/`. Not indexed by search engines (noindex). The live site stays at scorefex.com.
